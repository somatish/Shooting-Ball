# Shooting Ball 🎯

A simple and interactive browser-based shooting game built using HTML, CSS, and Vanilla JavaScript. The player must click on falling objects to score points before they reach the bottom of the game area.

## Features

* Interactive shooting gameplay
* Real-time score tracking
* Random object generation
* Falling object animation
* Click detection system
* Dynamic DOM manipulation
* Responsive game interface

## Gameplay

* Red circular objects fall from the top of the screen.
* The player must click on the objects before they reach the bottom.
* Each successful hit increases the score.
* Objects continuously spawn during gameplay.
